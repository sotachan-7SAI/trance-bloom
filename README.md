# TRANCE BLOOM

手を動かすと、音と光がひらく。トランスと瞑想の空間です。

**▶ https://sotachan-7sai.github.io/trance-bloom/**

スマホ・PC（Mac / Windows）・Meta Quest のブラウザで、そのまま開けます。アプリを入れる必要はありません。

## 遊び方

| 端末 | 開き方 | さわり方 |
|---|---|---|
| スマホ | アドレスを開いて「▶ はじめる」 | タップ = 鐘と波紋 ／ 指でなぞる = 見まわす ／ 長押し = 星くずを吸いよせる ／ 📱 = 傾けて見まわす ／ ☰ = メニュー |
| PC | アドレスを開いて「▶ はじめる」 | クリック = 鐘と波紋 ／ 右ボタンを押したまま = 吸いよせる ／ M = メニュー ／ ←→ = 見まわす ／ H = 操作の説明 |
| Meta Quest | Quest のブラウザでアドレスを開いて「🥽 VR に入る」 | トリガー = 鐘 ／ 握る = 吸いよせる ／ B = メニュー ／ A = 光が爆ぜる（くわしくは、はじめの画面の説明） |

- メニュー: 🎆 ショー（拍で場面が変わる）・🌌 世界・🧪 GLSL の世界（無限の構造物 8 つ）・🎲 バリエーション（色・形・速さちがい）・🚀 旅（8 分）・🎐 自動演奏 など
- 🎵 自分の端末の曲で演出できます（曲はブラウザの中だけで読みます。どこにも送りません）。Quest で使う曲は、VR に入る前に「🎵 曲を選ぶ」で選んでおきます
- 音が出ます。iPhone は消音モードだと音が出ないことがあります
- スマホと Quest では、軽く動くように星くずの数と絵の細かさを減らしています
